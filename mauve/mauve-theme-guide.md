Mauve is a responsive, single-column Tumblr theme with a fixed sidebar. On smaller screens, the sidebar becomes a slide-in menu. Optional dark mode, search bar, and update tab included. Full support of NPF posts.

Options like custom post width, font size and font-family, photoset gutter, post information, tag display, sidebar image size and shape, and custom navigation labels. Optional update tab, as well as choices between sharp or rounded corners.

Browse through the guide to see all options and customizable functions.

# Getting started

Mauve is a responsive theme, so depending on your screen size, the customization window might take up a lot of the space resulting in the theme to look different. Also, the Tumblr preview window rarely displays the exact product, so before messaging me please do the following:

- Change and toggle the options in the customization panel.
- Hit save and go to your blog URL and view it.

## Mobile theme

Like previously mentioned, my themes are responsive. Tumblr provides its own mobile theme (looks like the app or dashboard on web browser). If you wish to use this theme for mobile as well, do the following:

1. In your theme editor, scroll down to the bottom of the customization panel and click on **Advanced options**.
2. Toggle off **Use default mobile theme** option.

# Installation

1. Click the link for the code in the theme post, and you'll be directed to a GitHub file.
2. Click the **Copy raw file** button in the top-right area of the GitHub file.
3. Go to `tumblr.com/customize/[YOUR-BLOG-URL]` and you will be redirected to your blog's customization page.
4. **Please note:** if you have a previous theme's code installed, first reset your theme options by going to Browse themes → Tumblr Official → Use → Save.
5. Click **Edit HTML**, delete all existing code, then paste in Mauve's code.
6. Click **Update**, then **Save**.

# Select options

Here you can select a variety of things from dropdown menus.

## Font Size

Choose between `11px` to `18px`.

## Post Width

Choose between `350px`, `400px`, `450px`, `500px`, and `540px`.

`540px` is the standard post width on the Tumblr dashboard.

## Photoset Gutter

The gutter is the gap between photos in photosets. Choose between `1px`–`4px`.

`4px` is the standard size on the dashboard.

## Post Info

Post info involves the dates, note count, and interactives like tags, reblog, and like buttons.

| **Option** | **Description**        |
| ---------- | ---------------------- |
| Icons      | icons across the board |
| Text       | text across the board  |

## Display Tags

Choose between:

| **Option**  | **Description**                              |
| ----------- | -------------------------------------------- |
| Always      | always displays the tags                     |
| Upon Toggle | displays the tags when the toggle is clicked |

## Sidebar Image Size

This controls the size of the sidebar image. Choose between `40px`, `55px`, or `70px`.

## Sidebar Image Shape

Choose between square, rounded, circle, or blob.

| **Option** | **Description**      |
| ---------- | -------------------- |
| Square     | Square image shape   |
| Rounded    | Rounded image shape  |
| Circle     | Circular image shape |
| Blob       | Blob image shape     |

# Boolean options

Here you can toggle on/off a variety of options.

## Dark Mode

If you decide to offer Dark Mode, toggle this on. The Dark Mode detects if the visitor's operating system is on dark mode and displays that choice at first visit, with the option to toggle the other mode on/off.

## Hide Tumblr Controls

Toggle this on to hide the Tumblr controls from your blog.

## Round Content Corners

This concerns the content boxes of the theme. Toggled off you will have square sharp corners. Toggled on, rounded soft corners.

## Round Photo Corners

This concerns the photos and photosets of the theme. Toggled off you will have square sharp corners. Toggled on, rounded soft corners.

## Accented Pinned Post

Toggle this on to display an accent-coloured divider and pin icon above pinned posts.

## Search Bar

Toggle this on to offer a search bar on your blog.

# Text fields: Customization

The following are text fields where you type text to change things or delete text to hide them.

## Body Font

You can freely decide on a Google Font of your choice for your blog. Go to `fonts.google.com` and copy the name of the font you want into the text field.

Default: `Inter`

## Post Margin

The post margin is the gap between posts. Please keep a number in this. If you don't want any gap, write `0px`.

Default: `130px`

## Custom Title

The title in the sidebar, which is optional.

Default: `lorem ipsum`

## Custom Description

The description text is optional. It can contain HTML like links, ~~strikethrough~~, **bold**, <u>underline</u>, and _italic_ text.

Default: `This is where your description text goes. Links and html is allowed.`

## Menu Title

The title displayed above the navigation links.

Default: `menu`

The following are text fields concerning the navigation links.

| **Text Field**      | **Default**   | **Description**                                 |
| ------------------- | ------------- | ----------------------------------------------- |
| Home Link Title     | `home`        | The label for the link to your blog's home page |
| Home Link Icon      | `home`        | The icon displayed next to your Home link       |
| Ask Link Title      | `ask`         | The label for your Ask link                     |
| Ask Link Icon       | `mail`        | The icon displayed next to your Ask link        |
| Navigate Link Title | `more`        | The label for your Navigate link                |
| Navigate Link Icon  | `layout-grid` | The icon displayed next to your Navigate link   |
| Archive Link Title  | `Archive`     | The label for your archive link                 |

The **Ask** link will only show up on your blog if you have enabled the respective option in your Tumblr blog settings.

Go to:

`tumblr.com/settings/blog/[YOUR-BLOG-URL]`

and enable the option there.

## Adding your own links

Your own links can be added through Tumblr Pages.

For your links to appear in the Navigate menu, create or edit a Tumblr page and enable **Show a link to this page**, then give it a link title.

If you need to link to a Tumblr tag page, or literally anywhere else on the internet, choose **Link** in the page type dropdown and give it a link title.

# Text fields: Update Tab

The **Update Tab Title**, **Update Tab**, and **Activity [#]** fields control the content displayed in the Update Tab.

The Update Tab is positioned in the top-right corner of the blog.

The **Update Tab** and **Activity [#]** fields can contain HTML like links, etc. You can learn about changing the icons under **Change icons**.

The default fields are:

| **Text Field**   | **Default**                                | **Description**             |
| ---------------- | ------------------------------------------ | --------------------------- |
| Update tab Title | `Updates`                                  | The title of the Update Tab |
| Update Tab       | `updates text. Links and html is allowed.` | The main Update Tab text    |
| Activity 1 Icon  | `tv`                                       | The icon for Activity 1     |
| Activity 1       | `watching`                                 | The text for Activity 1     |
| Activity 2 Icon  | `music`                                    | The icon for Activity 2     |
| Activity 2       | `listening`                                | The text for Activity 2     |
| Activity 3 Icon  | `library`                                  | The icon for Activity 3     |
| Activity 3       | `reading`                                  | The text for Activity 3     |
| Activity 4 Icon  | `gamepad-2`                                | The icon for Activity 4     |
| Activity 4       | `playing`                                  | The text for Activity 4     |

You can change both the icon and the text to whatever you want.

# Change icons

You're able to change the four activity icons in the Update Tab, as well as the icons used for the Home, Ask, and Navigate links.

For this theme, I'm utilizing **Lucide**.

1. Go to [lucide.dev](https://lucide.dev/).
2. Search for the icon you want.
3. Click on your chosen icon.
4. Copy the name of the icon.
5. Copy that into the respective text field.

For example:

`music`

or:

`gamepad-2`

The icon name should be entered into the respective **Icon** field.
