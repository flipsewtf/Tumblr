Broek is a responsive Tumblr theme with a single post column and a sticky sidebar that can be positioned on either the left or right side.

Optional dark mode, search bar, update tab, Tumblr controls, and centred post column included. Full support of NPF posts.

Options include custom font size, post width, photoset gutter, post information, tag display, sidebar image size and shape, blog layout, and post spacing. Choose between different sidebar positions and optional rounded corners.

Browse through the guide to see all options and customizable functions.

---

# Getting started

Broek is a responsive theme, so depending on your screen size, the customization window might take up a lot of the space resulting in the theme to look different. Also, the Tumblr preview window rarely displays the exact product, so before messaging me please do the following:

- Change and toggle the options in the customization panel.
- Hit save and go to your blog URL and view it.

## Mobile theme

Like previously mentioned, my themes are responsive. Tumblr provides its own mobile theme (looks like the app or dashboard on web browser). If you wish to use this theme for mobile as well, do the following:

1. In your theme editor, scroll down to the bottom of the customization panel and click on **Advanced options**.
2. Toggle off **Use default mobile theme** option.

# Installation

1. Click the link for the code in the theme post, and you'll be directed to a GitHub file.
2. Click the **Copy raw file** button in the top-right area of the GitHub file.
3. Go to `tumblr.com/customize/[YOUR-BLOG-URL]` and you will be redirected to your blog's customization page.
4. **Please note:** if you have a previous theme's code installed, first reset your theme options by going to Browse themes → Tumblr Official → Use → Save.
5. Click **Edit HTML**, delete all existing code, then paste in Broek's code.
6. Click **Update**, then **Save**.

# Select options

Here you can select a variety of things from dropdown menus.

## Blog Layout

Choose between:

| **Option**    | **Description**                   |
| ------------- | --------------------------------- |
| Left Sidebar  | Displays the sidebar on the left  |
| Right Sidebar | Displays the sidebar on the right |

## Font Size

Choose between `1.1rem` (11px) to `1.8rem` (18px).

## Post Width

Choose between `350px`, `400px`, `450px`, `500px`, and `540px`.

`540px` is the standard post width on the Tumblr dashboard.

## Photoset Gutter

The gutter is the gap between photos in photosets. Choose between `1px`–`4px`.

`4px` is the standard size on the dashboard.

## Sidebar Image Size

This controls the size of the sidebar image.

Choose between `60px`, `80px`, or `100px`.

## Sidebar Image Shape

Choose between:

| **Option** | **Description**      |
| ---------- | -------------------- |
| Square     | Square image shape   |
| Rounded    | Rounded image shape  |
| Circle     | Circular image shape |
| Blob       | Blob image shape     |

## Post Info

Post info involves the dates, note count, and interactives like tags, reblog, and like buttons.

| **Option** | **Description**        |
| ---------- | ---------------------- |
| Icons      | Icons across the board |
| Text       | Text across the board  |

## Tags

Choose how your tags are displayed.

| **Option**  | **Description**                |
| ----------- | ------------------------------ |
| Always      | Displays the tags normally     |
| Upon Toggle | Hides the tags behind a toggle |

## Update Tab

Choose whether the Update Tab is hidden or displayed in the top-left corner.

| **Option**  | **Description**                                |
| ----------- | ---------------------------------------------- |
| Hidden      | The Update Tab is hidden                       |
| Left Corner | Displays the Update Tab in the top-left corner |

# Boolean options

Here you can toggle on/off a variety of options.

## Hide Tumblr Controls

Toggle this on to hide the Tumblr controls behind a button in the top-right corner of the theme.

## Dark Mode

If you decide to offer Dark Mode, toggle this on. The Dark Mode detects if the visitor's operating system is on dark mode and displays that choice at first visit, with the option to toggle the other mode on/off.

## Center Post Column

Toggle this on to centre the post column on the page instead of positioning it directly beside the sidebar.

## Round Content Corners

This concerns the content boxes of the theme.

- **Off** — square, sharp corners.
- **On** — rounded, soft corners.

## Round Photo Corners

This concerns the photos and photosets of the theme.

- **Off** — square, sharp corners.
- **On** — rounded, soft corners.

## Search Bar

Toggle this on to display a search bar in the sidebar.

# Text fields: Customization

The following are text fields where you type text to change things or delete text to hide them.

## Body Font

You can freely decide on a Google Font of your choice for the main text of your blog. Go to `fonts.google.com` and copy the name of the font you want into the text field.

Default: `Inter`

## Post Margin

The post margin is the gap between posts. Please keep a valid CSS length value in this field. If you don't want any gap, write `0rem`.

Default: `100px`

## Custom Title

The optional title displayed in the sidebar.

Default: `lorem ipsum`

## Custom Description

The optional description text.

It can contain HTML like links, bold, underline, or italic text.

Default: `This is where your description text goes. Links and html is allowed.`

# Text fields: Navigation

The following are text fields concerning the navigation links.

| **Text Field**     | **Default** | **Description**                                 |
| ------------------ | ----------- | ----------------------------------------------- |
| Home Link Title    | `home`      | The label for the link to your blog's home page |
| Ask Link Title     | `ask`       | The label for your Ask link                     |
| Archive Link Title | `archive`   | The label for your archive link                 |

The **Ask** link will only show up on your blog if you have enabled the respective option in your Tumblr blog settings.

Go to:

`tumblr.com/settings/blog/[YOUR-BLOG-URL]`

and enable the option there.

The **Submit** link uses Tumblr's built-in **Submit** label and cannot be customised through the theme.

### Adding your own links

Your Tumblr pages appear in the navigation automatically.

For your links to appear in the navigation, create or edit a Tumblr page and enable **Show a link to this page**, then give it a link title.

If you need to link to a Tumblr tag page, or literally anywhere else on the internet, choose **Link** in the page type dropdown and give it a link title.

# Text fields: Update Tab

The **Update Tab** title, update text, activity text fields, and activity icons control the content displayed in the Update Tab.

The Update Tab can be positioned in the top-left corner of the theme.

The **Update Tab text** and activity text fields can contain HTML like links, etc. You can learn about changing the icons under **Change icons**.

## Activities

| **Text Field**   | **Default**                                | **Description**                |
| ---------------- | ------------------------------------------ | ------------------------------ |
| Update tab Title | `Updates`                                  | The title displayed in the tab |
| Update Tab text  | `updates text. Links and html is allowed.` | The introductory update text   |
| Activity 1 Icon  | `television-simple`                        | The icon for Activity 1        |
| Activity 1       | `watching`                                 | The text for Activity 1        |
| Activity 2 Icon  | `headphones`                               | The icon for Activity 2        |
| Activity 2       | `listening`                                | The text for Activity 2        |
| Activity 3 Icon  | `books`                                    | The icon for Activity 3        |
| Activity 3       | `reading`                                  | The text for Activity 3        |
| Activity 4 Icon  | `game-controller`                          | The icon for Activity 4        |
| Activity 4       | `playing`                                  | The text for Activity 4        |

You can change both the icon and the text to whatever you want.

If you delete the text from an **Activity [#]** field, that activity will be hidden. If you delete the text from an **Activity [#] Icon** field, the activity will remain but the icon will be hidden.

# Change icons

You're able to change the four activity icons in the Update Tab. For this theme, I'm utilizing **Phosphor Icons**.

1. Go to `phosphoricons.com`.
2. Search for the icon you want.
3. Click on your chosen icon.
4. Copy the name of the icon.
5. Copy that into the respective text field.

For example:

`television-simple`

or:

`game-controller`

The icon name should be entered into the respective **Activity [#] Icon** field.
