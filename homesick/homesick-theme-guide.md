# Getting started

Homesick is responsive, so depending on your screen size, the customisation panel may take up a lot of space and cause the theme to render differently while you're editing. The Tumblr preview window also doesn't always reflect the real thing. Before messaging me, please:

- Change and toggle the options in the customisation panel.
- Hit save, then view your actual blog URL.

## Mobile theme

Tumblr provides its own mobile theme (the one that resembles the app or dashboard). If you'd like Homesick to be used on mobile as well:

1. In the theme editor, scroll to the bottom of the customisation panel and open **Advanced options**.
2. Toggle off **Use default mobile theme**.

# Installation

1. Click the Ko-fi link in the theme post — you'll be directed to my [Ko-fi shop](https://ko-fi.com/flipse/shop).
2. Once purchased, you'll receive a `.txt` file.
3. Open it in Notepad (or similar) and copy the entire code.
4. Go to `tumblr.com/customize/[YOUR-BLOG-URL]`.
5. **Please note:** if you have a previous theme's code installed, first reset your theme options by going to Browse themes → Tumblr Official → Use → Save.
6. Click **Edit HTML**, delete all existing code, then paste in Homesick's code.
7. Click **Update**, then **Save**.

# Colours

Here you can change the colours of the theme.

If you are not offering dark mode, you do not need to worry about the dark mode colours.

Click the colour circles in Tumblr's customisation panel to change a colour. A colour picker will appear.

The six-digit number preceded by `#` is a hexadecimal colour code.

For a more specific colour picker, you can use [RedKetchup's Color Picker](https://redketchup.io/color-picker). You can choose a colour and copy its hex code, or even pick a colour from a photo.

# Boolean options

Here you can toggle a variety of options on or off.

## Dark Mode

If you decide to offer dark mode, toggle this on.

The dark mode detects whether the visitor's operating system is using dark mode and displays that choice on their first visit, with the option to toggle between light and dark mode.

## Hide Tumblr Controls

Toggle this on to hide the Tumblr controls behind a toggle button.

## Round Content Corners

This concerns the content of the theme.

- **Off** — sharp, square corners.
- **On** — rounded corners.

## Update Tab

If toggled on, the Update Tab is positioned below the navigation in the sidebar.

## Search Bar

Toggle this on to offer a search bar on your blog.

The search bar is positioned above the navigation in the sidebar.

# Text fields: Customization

The following are text fields where you type text to change things or delete text to hide them.

## Body Font

You can freely choose a Google Font for your blog.

Go to [fonts.google.com](https://fonts.google.com/) and copy the name of the font you want into the text field.

Default: `Inter`

## Secondary Font

The secondary font affects the search field, Update Tab activities, sidebar description, more-info popup on posts, and the footer credit.

You can freely choose a Google Font for these elements.

Go to [fonts.google.com](https://fonts.google.com/) and copy the name of the font you want into the text field.

Default: `Roboto Mono`

## Post Margin

The post margin is the gap between posts.

Please keep a number in this. If you don't want any gap, write `0`.

Default: `100px`

## Name

This is the text at the top of the sidebar. It is optional.

Default: `Jane Doe`

## Location Icon

This is the icon for the location text. See **Change icons** for information about changing it.

Default: `map-pin`

## Location

This is the location text. You can use it for whatever you want.

Default: `Narnia`

## Custom Title

The custom title is displayed in the sidebar.

It is optional, so simply delete the text in the field if you wish to hide it.

Default: `lorem ipsum`

## Custom Description

The custom description is displayed in the sidebar.

It is optional, so simply delete the text in the field if you wish to hide it.

It can contain HTML such as links, **bold**, <u>underline</u>, ~~strikethrough~~, or _italic_ text.

Default: `This is where your description text goes. Links and html is allowed.`

## Adding your own links

Your own links can be added through Tumblr Pages.

Your Tumblr pages and custom links appear in a hidden menu accessed through the three-dot menu in the navigation bar.

For your links to appear in the navigation, create or edit a Tumblr page and enable **Show a link to this page**, then give it a link title.

If you need to link to a Tumblr tag page, or literally anywhere else on the internet, choose **Link** in the page type dropdown and give it a link title.

# Change icons

You're able to change the icons used throughout the theme.

Homesick uses **Phosphor Icons**.

1. Go to [phosphoricons.com](https://phosphoricons.com/).
2. Search for the icon you want.
3. Click on your chosen icon.
4. Copy the icon name.
5. Paste the name into the corresponding icon text field.

For example:

`television-simple`

The icon name can be entered into fields such as **Location Icon**, **Home Link Icon**, **Ask Link Icon**, **Toggle Icon**, **Update Toggle Icon**, and the **Activity [#] Icon** fields.
